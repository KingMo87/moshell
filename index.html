REFERENCEGetting started

Set Up Your Linux VM

The recommended setup for following every MOSHELL lesson. It uses VirtualBox and Ubuntu Server, both free and beginner friendly.

1
Download VirtualBox
Get the latest VirtualBox from virtualbox.org. It is free and works on Windows, macOS and Linux. Install with the default settings.
2
Download Ubuntu Server ISO
Get Ubuntu Server LTS from ubuntu.com. Use the Server edition, not Desktop. It is lighter and makes you work in the CLI, which is how real servers operate.
3
Create the VM
In VirtualBox: New → name it moshell-lab → Linux / Ubuntu 64-bit. Assign at least 2048 MB RAM and a 20 GB virtual disk. Leave everything else as default.
4
Attach ISO and Install
Settings → Storage → attach the .iso as a virtual CD. Boot and follow the Ubuntu installer. Accept the defaults. When asked about partitioning, choose Use an Entire Disk.
5
Configure Network Adapter
NAT is the default and gives internet access. Bridged gives the VM its own IP on your LAN. Host-Only is an isolated network between host and VM. For multi-VM labs, use Host-Only or Internal Network. Lesson 09 covers this in full.
6
Take a Snapshot
Before anything else: Machine → Take Snapshot, named clean-install. Always snapshot before destructive exercises. Breaking your VM is part of learning. Restore it and try again.
7
First Commands to Run
After the first boot, run sudo apt update && sudo apt upgrade -y to update packages. Then run ip a to confirm networking. You are ready to start Lesson 01.
